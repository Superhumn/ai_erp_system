## How to read this

For every page under `client/src/pages/`, this document lists:
- **Component**, **Route(s)**, **Sidebar section** (from `client/src/App.tsx` + `DashboardLayout.tsx` per CLAUDE.md's canonical structure).
- **tRPC calls** — every `trpc.X.Y.useQuery/useMutation/...` invoked from the page.
- **Buttons** — every `<Button>` with label, line number, and flags: `no onClick` (no inline handler — likely fine if wrapped by DialogTrigger), `disabled-attr` (renders disabled in some state), variant.
- **Dialog triggers / Menu items / Nav links / Form submits** — other action surfaces.
- **Primary domain(s)** — the most-frequent tRPC top-level namespace(s) on the page.
- **Mutations available but NOT called from this page** — candidate missing buttons.

### Honest caveats

- The gap analysis is a **signal, not a directive**. Many "missing" mutations are by-design absent — e.g. a public read-only page shouldn't expose `*.update` / `*.delete`. Use the list as a starting checklist, not a backlog.
- The button-label regex is naive: when a button's contents include `{expr}` interpolations, the label captured may include surrounding code fragments. Treat labels as identifiers, not pixel-perfect text.
- A page that calls `customers.create` but not `customers.update` may be intentional if updates happen on a sibling detail page. Cross-reference with related pages (e.g. `Customers.tsx` and `CustomerDetail.tsx`) before concluding a gap.
